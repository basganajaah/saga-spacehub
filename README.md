# Saga Spacehub — Personal Digital Hub

Single-screen bento-grid personal hub. Next.js (App Router) + TypeScript + CSS Modules.
All dependencies are free and open source (MIT): `next`, `react`, `motion`, `typewriter-effect`, `lucide-react`. Font: Inter via `next/font` (SIL OFL).

## Run

```bash
npm install
npm run dev
npm run build && npm start
```
